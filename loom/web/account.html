Connect in minutes

1
Install the CLI.
curl -fsSL https://raw.githubusercontent.com/rj-Anurag/Loom/main/install.sh | bash
2
Connect this repository.
loom login --email you@example.com --write-env .env
3
Install the bundled extension.
loom extension install --force
